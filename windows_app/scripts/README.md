# Windows应用脚本目录

这个目录包含了牙医诊所管理系统Windows应用相关的手动执行工具脚本。

**注意**: 这些脚本是独立的工具脚本，不会被应用代码调用，需要用户手动执行。

## 脚本说明

### clear_app_data.bat
**用途**: 清除应用的所有数据和配置
**功能**:
- 删除用户文档目录下的应用数据 (`%USERPROFILE%\Documents\DentistApp`)
- 删除本地应用数据缓存 (`%LOCALAPPDATA%\DentistApp`)
- 删除漫游应用数据 (`%APPDATA%\DentistApp`)
- 清除注册表中的SharedPreferences配置

**使用场景**:
- 应用出现配置问题需要手动重置
- 卸载应用前彻底清理数据
- 开发测试时需要手动清空数据
- 应用内重置功能无法解决问题时的备用方案

**使用方法**: 
- 双击运行，或在命令行中执行
- **重要**: 运行前请先关闭应用程序

### verify_mysql_tools.bat
**用途**: 验证MySQL工具是否正确安装
**功能**:
- 检查mysql.exe和mysqldump.exe是否可用
- 验证MySQL客户端工具的安装状态

**使用场景**:
- 配置MySQL数据源前的手动环境检查
- 排查MySQL备份功能问题
- 验证MySQL工具安装是否正确

**使用方法**: 
- 双击运行，或在命令行中执行
- 查看输出结果判断MySQL工具状态

## 注意事项

1. **这些脚本与应用代码无关**，是独立的手动工具
2. **clear_app_data.bat** 会永久删除所有应用数据，使用前请确保已备份重要数据
3. 某些操作可能需要管理员权限
4. 运行脚本前请先关闭应用程序
5. 这些脚本主要用于故障排除和维护目的
