# 牙科诊所管理系统打包指南

本文档提供了将牙科诊所管理系统打包为 Windows 单机版安装软件的详细步骤，以及如何在不同电脑上安装使用的说明。

## 一、打包为 EXE 可执行文件

### 1. 安装必要的打包工具

```bash
pip install pyinstaller
pip install pywin32
```

### 2. 运行打包脚本

项目中已包含`build_exe.py`打包脚本，直接运行即可：

```bash
python build_exe.py
```

打包完成后，可执行文件将生成在`dist`文件夹中。

### 3. 打包注意事项

- 确保所有依赖已正确安装（见`requirements.txt`）
- 打包前确保应用能正常运行
- 如果有静态资源文件，确保已在打包脚本中包含

## 二、创建安装程序

### 使用 Inno Setup 创建安装程序

1. 下载并安装[Inno Setup](https://jrsoftware.org/isdl.php)
2. 创建新的安装脚本，设置以下内容：
   - 应用名称：牙科诊所管理系统
   - 应用版本：1.0
   - 发布者：您的组织名称
   - 安装目录：默认为`C:\Program Files\牙科诊所管理系统`
   - 添加桌面快捷方式和开始菜单项
3. 添加`dist`文件夹中的所有文件到安装包
4. 编译脚本生成安装程序（.exe 文件）

## 三、数据库配置

### 本地 MySQL 数据库配置

安装程序需要包含以下内容：

1. MySQL 安装程序（可选，也可要求用户自行安装）
2. 数据库初始化脚本
3. 安装过程中配置数据库连接

### 使用 SQLite 作为替代（更适合单机版）

为了简化单机版部署，可以修改应用使用 SQLite 数据库：

1. 修改`.env`文件中的数据库连接为 SQLite：

   ```
   DATABASE_URL=sqlite:///dental_clinic.db
   SECRET_KEY=your_secret_key_here
   ```

2. 确保打包时包含 SQLite 数据库文件

## 四、在不同电脑上安装使用

### 安装步骤

1. 运行生成的安装程序（.exe 文件）
2. 按照安装向导提示完成安装
3. 如使用 MySQL，确保目标电脑已安装 MySQL 并正确配置
4. 如使用 SQLite，无需额外配置

### 首次运行

1. 通过桌面快捷方式或开始菜单启动应用
2. 首次运行时，系统会自动创建必要的数据库表
3. 创建管理员账户并登录系统

### 常见问题解决

1. 数据库连接错误：检查数据库服务是否启动，连接参数是否正确
2. 缺少依赖：确保打包时包含了所有必要的依赖库
3. 权限问题：以管理员身份运行应用或安装到非系统目录

## 五、备份与恢复

### 数据备份

1. MySQL 数据库：使用 MySQL 自带的备份工具导出数据
2. SQLite 数据库：备份数据库文件（dental_clinic.db）

### 数据恢复

1. MySQL 数据库：使用备份文件恢复数据
2. SQLite 数据库：替换数据库文件

---

通过以上步骤，您可以将牙科诊所管理系统打包为 Windows 11 下的单机版 exe 安装软件，并在不同电脑上直接安装使用。
